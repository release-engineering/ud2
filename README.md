# ud2

`ud2` is a CRUD/REST-oriented command line interface for managing products, versions, and repositories. The project currently contains scaffolding for command groups and verbs, with additional model details to be provided later.

## Development

- Run tests: `make test`
- Lint with flake8: `make lint`
- Build artifacts: `make build`
- Install locally: `make install`
- Create a source archive from git: `make archive`

All developer commands rely on `tox` environments to ensure consistency.
